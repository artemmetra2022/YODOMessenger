ИДЕИ ДЛЯ УЛУЧШЕНИЯ YODO MESSENGER
=================================

(актуализировано 28.08.2026: добавлены новые функции — напоминания о сообщениях, перевод одним тапом, шаблоны ответов, совместные списки, статистика каналов, кнопки в постах, passkeys, удалённая блокировка, поиск друзей из телефонной книги, напоминания о ДР, голосовые чаты, виджеты, управление памятью. 27.08.2026 — реализованные пункты удалены)

1. НАДЁЖНОСТЬ СООБЩЕНИЙ
-----------------------
- Очередь исходящих сообщений с повторной отправкой после восстановления сети и защитой от дублирования при повторной отправке.
- Синхронизация сообщений после длительного офлайн-режима: отправленные без сети должны уходить при её появлении.
- Пагинация истории: подгрузка старых сообщений при прокрутке вверх (сейчас чат загружает фиксированный хвост).

2. БЕЗОПАСНОСТЬ
---------------
- Проверка ключей собеседника: отпечатки ключей E2E в профиле + предупреждение «ключи изменились» (E2E на Tink уже есть, UI проверки — нет).
- Уведомление при входе с нового устройства.
- Биометрия (BiometricPrompt) как альтернатива PIN для входа и скрытых чатов.
- Автоматическая фильтрация спама и подозрительных ссылок (сейчас — только локальный rate limiter и ручные репорты).
- Вход по passkeys (WebAuthn) вместо пароля через Credential Manager (Google Sign-In уже подключён).
- Удалённая блокировка/стирание данных устройства из центра безопасности при потере или краже телефона.

3. ОФЛАЙН-РЕЖИМ / MESH
-----------------------
- Уровень сигнала соседних устройств в списке узлов mesh-сети.
- Индикатор маршрута конкретного сообщения (путь «откуда пришло», а не только число прыжков).
- Ограничение размера офлайн-медиа и прогресс передачи.
- Автоматическое удаление временных файлов после передачи.
- Тесты потери соединения, повторного подключения и передачи через несколько промежуточных устройств.
- Ограничение фоновой активности и расхода батареи в Nearby/mesh-режиме.

4. ЧАТЫ
-------
- Упоминания пользователей и уведомления о них.
- Синхронизация черновиков между устройствами (сейчас черновики только локальные).
- Резервное копирование/восстановление истории чатов (экспорт уже есть, нужны импорт и автобэкап).
- Напоминания о конкретных сообщениях («напомнить в 20:00») через WorkManager.
- Перевод сообщений одним тапом (Firebase ML / LLM API).
- Шаблоны быстрых ответов (свои заготовки с подстановкой из панели).
- Совместные списки/задачи в чате (общий чек-лист группы).

5. ГРУППЫ И КАНАЛЫ
------------------
- Медленный режим для групп (slow mode).
- Полная синхронизация нескольких аккаунтов: бесшовное переключение и корректная обработка push при нескольких аккаунтах.
- Статистика для админов каналов: просмотры постов, прирост подписчиков, графики.
- Кнопки в постах каналов («Подписаться», «Перейти по ссылке», quick-reply).

6. УВЕДОМЛЕНИЯ
--------------
- Действия в уведомлениях: ответить, отметить прочитанным, отключить (сейчас уведомление только открывает чат).
- Тихие часы — график беззвучных уведомлений.

7. НОВЫЕ ФУНКЦИИ / ИННОВАЦИИ
----------------------------
- AI-ассистент в чате: резюме непрочитанных сообщений, умные ответы, бот в чате поддержки (Firebase Functions + LLM API).
- Живая геолокация: «поделиться геопозицией на 15 минут / 1 час» с обновлением в реальном времени (отправка точки и карта уже есть).
- Видеосообщения «кружком»: запись 15 сек в одном потоке с голосовыми.
- Истории/статусы на 24 часа.
- Стикеры и GIF-панель (пакеты WebP в Firebase Storage + пикер в чате).
- Звонки: голосовые и видео (WebRTC) + экран недавних звонков.
- Голосовые чаты в группах (voice chat, WebRTC).
- Виджеты на домашний экран: последний чат, счётчик непрочитанных.

8. ПРОИЗВОДИТЕЛЬНОСТЬ
---------------------
- Оптимизация Compose recomposition в списках чатов и сообщений.
- Профилирование прокрутки длинных чатов.
- Сбор отчётов о сбоях (Crashlytics) и обезличенных метрик производительности.
- Управление памятью: экран «Что занимает место» (размер кэша медиа по чатам) + точечная очистка.

9. ЛОКАЛИЗАЦИЯ
--------------
- Мультиязычность (i18n): вынести захардкоженные русские строки в ресурсы, добавить локали.

10. ТЕСТИРОВАНИЕ И КАЧЕСТВО
---------------------------
- Unit-тесты ViewModel и репозиториев (сейчас покрыты только утилиты — 6 тестов).
- Интеграционные тесты Firebase Rules.
- UI-тесты основных сценариев: регистрация, создание группы, отправка сообщения, офлайн-синхронизация.
- Тесты миграций Room и DataStore.
- Проверка доступности: TalkBack, крупный шрифт, контраст, работа без жестов.
- CI: запуск unit-тестов и статического анализа (ktlint/detekt) на каждый push, сборка release с подписью и загрузка mapping-файлов (сейчас — только debug APK вручную).

11. ДОКУМЕНТАЦИЯ
----------------

12. КОНТАКТЫ
------------
- Поиск друзей из телефонной книги: сопоставление контактов телефона с пользователями (по номеру, как в Telegram) — сейчас добавление только по QR/поиску.
- Напоминания о днях рождения контактов (дата рождения уже есть в профиле) + экран «ДР контактов».

БЛИЖАЙШИЕ ПРИОРИТЕТЫ
====================
1. Очередь исходящих сообщений с повтором и дедупликацией.
2. Полная офлайн-синхронизация (отправка без сети + подгрузка истории).
3. Проверка ключей собеседника (отпечатки E2E).
4. Медленный режим групп.
5. Видеосообщения «кружком».
6. AI-ассистент в чате (резюме непрочитанных, умные ответы).
7. UI-тесты ключевых пользовательских сценариев.
