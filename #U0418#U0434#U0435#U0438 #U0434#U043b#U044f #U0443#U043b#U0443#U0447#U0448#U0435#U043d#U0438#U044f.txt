ИДЕИ ДЛЯ УЛУЧШЕНИЯ YODO MESSENGER
=================================

1. НАДЁЖНОСТЬ СООБЩЕНИЙ
-----------------------
- Добавить очередь исходящих сообщений с повторной отправкой после восстановления сети.
- Сделать явные статусы: «отправляется», «доставлено», «прочитано», «ошибка».
- Реализовать защиту от дублирования сообщений при повторной отправке.
- Добавить синхронизацию сообщений после длительного офлайн-режима.

2. БЕЗОПАСНОСТЬ
---------------
- Добавить сквозное шифрование содержимого сообщений, а не только локальных данных.
- Реализовать проверку устройств и ключей собеседника.
- Добавить уведомление при входе с нового устройства.
- Установить ограничение количества попыток ввода PIN-кода и кода 2FA.
- Проверить Firestore Rules для удалённых, архивных и приватных данных.

3. ОФЛАЙН-РЕЖИМ
---------------
- Показывать список найденных устройств поблизости с уровнем сигнала и временем обнаружения.
- Добавить индикатор маршрута сообщения через mesh-сеть.
- Ограничить размер офлайн-медиа и показывать прогресс передачи.
- Реализовать автоматическое удаление временных файлов после передачи.
- Добавить тесты потери соединения, повторного подключения и передачи через несколько промежуточных устройств.

4. ЧАТЫ
-------
- Добавить поиск внутри конкретного чата с переходом к найденному сообщению.
- Реализовать закреплённые сообщения.
- Добавить редактирование сообщений с отметкой «изменено».
- Реализовать упоминания пользователей и уведомления о них.
- Добавить быстрые ответы свайпом.
- Синхронизировать черновики между устройствами.
- Добавить пагинацию истории сообщений для снижения расхода памяти.

5. ГРУППЫ И КАНАЛЫ
------------------
- Реализовать полноценную систему разрешений: отправка сообщений и медиа, приглашения, закрепление и удаление.
- Добавить медленный режим для групп.
- Сделать предпросмотр ссылки-приглашения.
- Добавить историю изменений ролей и настроек группы.
- Реализовать автоматическую фильтрацию спама и подозрительных ссылок.
- Завершить разработку опросов.

6. УВЕДОМЛЕНИЯ
--------------
- Добавить настройки уведомлений отдельно для каждого чата.
- Реализовать действия в уведомлениях: ответить, отметить прочитанным, отключить.
- Группировать уведомления от одного чата.
- Обеспечить корректную обработку push-уведомлений при использовании нескольких аккаунтов.

7. ПРОИЗВОДИТЕЛЬНОСТЬ
---------------------
- Добавить кэширование изображений и миниатюр.
- Оптимизировать Compose recomposition в списках чатов и сообщений.
- Провести профилирование прокрутки длинных чатов.
- Ограничить фоновую активность и расход батареи в Nearby/mesh-режиме.
- Добавить сбор отчётов о сбоях и обезличенных метрик производительности.

8. НЕЗАВЕРШЁННЫЕ ФУНКЦИИ
------------------------
- Реализовать звонки и экран недавних звонков.
- Завершить вход по номеру телефона.
- Реализовать опросы в группах.
- Доработать полную синхронизацию нескольких аккаунтов.
- Расширить возможности комментариев к постам каналов.

9. ТЕСТИРОВАНИЕ И КАЧЕСТВО
--------------------------
- Добавить unit-тесты для ViewModel и репозиториев.
- Добавить интеграционные тесты Firebase Rules.
- Создать UI-тесты основных сценариев: регистрация, создание группы, отправка сообщения и офлайн-синхронизация.
- Добавить тесты миграций Room и DataStore.
- Проверить доступность интерфейса: TalkBack, крупный шрифт, контраст и работа без жестов.
- Настроить CI-проверки debug/release-сборок, тестов и статического анализа.

10. ДОКУМЕНТАЦИЯ
----------------
- Использовать в CHANGELOG.txt версии и разделы Added, Changed, Fixed и Security.
- Описать архитектуру приложения и поток отправки сообщения.
- Добавить инструкцию запуска Firebase Emulator Suite.
- Описать ограничения офлайн-режима и известные проблемы.
- Добавить CONTRIBUTING.md с правилами разработки и тестирования.

БЛИЖАЙШИЕ ПРИОРИТЕТЫ
====================
1. Надёжная очередь исходящих сообщений.
2. Полная офлайн-синхронизация.
3. Проверка и тестирование Firestore Rules.
4. Поиск внутри чатов.
5. Закреплённые сообщения.
6. UI-тесты ключевых пользовательских сценариев.
