ИЗМЕНЕНИЯ ДЛЯ АДМИНОВ (ГРУППЫ И МОДЕРАЦИЯ)
============================================

Обновление от 27 августа 2026


УДАЛЕНИЕ ЧУЖИХ СООБЩЕНИЙ (МОДЕРАЦИЯ)
------------------------------------
- Владелец группы/канала, назначенный админ и участники с ролью,
  дающей право удаления сообщений (Модератор, Помощник или кастомная
  роль с правом DELETE_MESSAGES), теперь могут удалять чужие сообщения.
- В меню чужого сообщения появился пункт «Удалить для всех»
  (красный) с диалогом подтверждения.
- Модератор может удалять чужие сообщения и пакетно — в режиме выбора
  нескольких сообщений.
- Каждое удаление чужого сообщения автоматически записывается в журнал
  действий администраторов (MESSAGE_DELETED). Запись появляется только
  после фактического успешного удаления.
- В личных чатах модерация чужих сообщений отключена (только свои
  сообщения и жалобы, как раньше).


ГРУППЫ В ПОИСКЕ
---------------
- Открытые и модерируемые группы теперь находятся через общий поиск
  приложения (отдельная секция «Группы» с иконкой группы).
- Скрытые группы (HIDDEN) в поиске не видны никому, кроме их участников.
- Подсказка поиска обновлена: «…или группы и каналы по названию».
- В карточке группы: число участников с правильным склонением
  (1 участник / 2 участника / 5 участников), бейдж «Вы участник».


ПРОФИЛЬ ГРУППЫ И ВСТУПЛЕНИЕ
----------------------------
- Новый экран «О группе» — открывается из поиска для группы, в которой
  пользователь ещё не состоит.
- Открытая группа: кнопка «Вступить» (одним нажатием).
- Модерируемая группа: «Подать заявку» / «Заявка отправлена · отменить».
- Участник или владелец: кнопка «Открыть чат».
- Показывается режим доступа группы (открытая / модерируемая / скрытая)
  с описанием.
- В кнопках есть индикатор загрузки; при отказе (например, из-за бана)
  выводится понятная ошибка, а не «тишина».


ЗАЯВКИ НА ВСТУПЛЕНИЕ В ГРУППЫ
------------------------------
- Владелец/админ группы видит на экране информации о группе секцию
  «Заявки на вступление» с кнопками «Одобрить» / «Отклонить».
- Одобрение добавляет пользователя в группу; отклонение удаляет заявку.
- Забаненный пользователь не может повторно подать заявку — только
  после разбана владельцем/админом.


УПРАВЛЕНИЕ УЧАСТНИКАМИ ГРУППЫ
------------------------------
- Владелец/админ: тап по участнику открывает меню действий —
  «Исключить из группы» и «Забанить» (обе операции с подтверждением).
- Исключение: участник удаляется из группы, но может вернуться по заявке.
- Бан: участник удаляется и заносится в чёрный список группы,
  самостоятельно вернуться не может.
- Секция «Забаненные» со списком заблокированных и кнопкой «Разбанить».
- Под именами участников отображаются их роли («Модератор», кастомная
  роль и т.д.) — видно всем участникам, как строка «Владелец».
- Владельца группы исключить/забанить нельзя.
- Все действия (исключение, бан) записываются в журнал администраторов.


БЕЗОПАСНОСТЬ (ПРАВИЛА FIRESTORE)
--------------------------------
- Самостоятельное вступление разрешено ТОЛЬКО в открытые группы и
  каналы: в чужие личные чаты, скрытые и модерируемые чаты добавить
  себя нельзя (раньше это была дыра).
- Забаненный не может сам вернуться ни через вступление, ни через заявку.
- Право модерации сообщений на сервере проверяет роль по тому же
  принципу, что и приложение (владелец / админ / роль с правом
  DELETE_MESSAGES, включая кастомные роли).
- Модератор может менять чужое сообщение только в форме «удаления»
  (очистка текста и медиа) — произвольно переписать чужой текст нельзя.
- Правила устойчивы к старым чатам без полей ролей/бан-листов
  (не ломают реакции, закрепления и заявки).


УЛУЧШЕНИЯ ИНТЕРФЕЙСА
---------------------
- Диалог действий над участником переработан в вертикальный список —
  кнопки больше не сжимаются и не налезают друг на друга.
- Кнопки «Одобрить»/«Отклонить» в заявках уплотнены, длинные имена
  обрезаются многоточием — вёрстка стабильна на узких экранах.
- Ошибки операций на экране группы показываются всплывающим
  сообщением (раньше были незаметны).
- Мелкие исправления текстов (повреждённые строки «Удалить»,
  «Не удалось отклонить заявку», «Не удалось забанить пользователя»).


ЧТО ПРОВЕРИТЬ ПОСЛЕ ОБНОВЛЕНИЯ
------------------------------
1. Поиск: находится ли группа по названию; скрытая группа не видна.
2. Профиль группы: «Вступить» в открытую, «Подать заявку» в
   модерируемую.
3. Заявки: одобрение/отклонение владельцем.
4. Модерация: удаление чужого сообщения с записью в журнал.
5. Исключение/бан участника; бан не даёт вернуться, разбан возвращает
   возможность подать заявку.

Примечание: изменения проверены статически; сборка приложения —
через GitHub Actions (build-apk.yml). Правила Firestore — через
deploy-firestore-config.yml.
