### 2. Индикатор печатания в групповых чатах
**Статус:** ✅ Полностью реализовано

- **Проблема:** Typing-индикатор работал только в приватных чатах (1-к-1)
  - Код проверял `otherUserId != null`, для групп условие не срабатывало
- **Решение:** Расширен `ChatUiState` полем `typingUserNames: List<String>`
- **Логика:** 
  - Для приватных чатов — как было (`isOtherUserTyping`)
  - Для групп — резолвятся имена печатающих участников через `chatRepository.getGroupInfo()`
  - Кэш имён сохраняется в `groupMemberNamesCache`, чтобы не запрашивать на каждый апдейт
- **UI:** В шапке чата под названием группы показывается:
  - `"Имя печатает..."` если печатает один
  - `"N печатают..."` если несколько

**Как это работает:**
1. Пользователь начинает печатать в группе → отправляется `setTyping(true)`
2. Firestore: документ чата, поле `typingUsers.<uid> = true`
3. Остальные участники видят в реальном времени: "Иван печатает..."
4. Когда пользователь отправит сообщение или закроет клавиатуру → `setTyping(false)`

### 3. Опросы (Polls)
**Статус:** 🚧 Модель и базовая логика (репозиторий и UI в разработке)

- **Модель:** Новый класс `Poll` в `Message.kt`
  ```kotlin
  data class Poll(
      val question: String,
      val options: List<String>,
      val votesByOption: Map<Int, List<String>> = emptyMap(),
      val isAnonymous: Boolean = true,
      val allowMultipleAnswers: Boolean = false,
      val isClosed: Boolean = false
  )
  ```
  - `votesByOption` — map индекса варианта на список uid проголосовавших
  - Позволяет подсчитать голоса и узнать, кто голосовал (если не анонимный опрос)

- **Message.poll:** Добавлено поле `poll: Poll?` в `Message`
  - `previewText()` показывает "📊 [вопрос]" если это опрос

**Что осталось:**
1. `MessageRepository.sendPoll(chatId, poll)` и `MessageRepositoryImpl`
2. `MessageRepository.voteInPoll(chatId, messageId, optionIndex, userId)`
3. UI создания опроса (диалог с формой)
4. UI голосования и отображения результатов в ChatScreen

## Примечания

1. **Архивация:** Использует **персональный flag** (`archived.$uid`), то есть каждый участник чата может архивировать его независимо. Архивация одного пользователя не видна другим — правильное поведение для приватных чатов и групп.

2. **Typing в группах:** Требует, чтобы `chatRepository.getGroupInfo()` вернул список участников с именами. Если в группе 100+ участников, может быть медленным, но кэш (`groupMemberNamesCache`) сохраняет результат первого вызова.

3. **Опросы:** Модель готова, но методы репозитория и UI пока не реализованы. Это прямолинейная работа (добавить пару методов в `MessageRepository`, UI composable с radio/checkbox). Хотите доделать?
