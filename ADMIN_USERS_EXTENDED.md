# Расширенное управление пользователями

Добавлено в админ-раздел `Пользователи`:
- поиск по имени, username и email;
- фильтры по статусу, стране и диапазону даты регистрации;
- статусы: Новичок (<7 дней), Активный, Неактивный (30+ дней), Заблокирован, На проверке;
- мультивыбор и групповая блокировка/разблокировка;
- причина и подробное описание блокировки;
- история блокировок/разблокировок;
- расширенная карточка пользователя;
- последние 5 сессий входа;
- число отправленных сообщений;
- число полученных жалоб;
- группы и каналы с ролью пользователя;
- список IP-адресов, если они поступают из серверного источника.

## Важное ограничение IP
Android Firebase Auth SDK не предоставляет приложению IP-адрес пользователя. Поэтому клиент записывает дату/провайдера/устройство, а `ipAddress` оставляет `null`. Структура Firestore готова принимать IP из серверного источника.

## Firestore
Добавлены:
- `adminLoginHistory/{uid}/entries/{entryId}`
- `users/{uid}/blockHistory/{entryId}`
- поля `users/{uid}.createdAt`, `lastActiveAt`, `country`, `accountStatus`

Администратор получает доступ к чтению сообщений для расчёта счётчика отправленных сообщений.


## Новые функции (добавлено)

### Статистика пользователя за 30 дней
- В карточке пользователя появился график активности по дням.
- Используются записи `adminLoginHistory/{uid}/entries`; последние 30 дней агрегируются по календарным дням.
- В карточке сохраняется только 5 последних входов в текстовом списке, а график использует более широкий период.

### Управление администраторами
- Главный администратор может выбрать пользователя и назначить роль:
  - Администратор
  - Модератор
  - Поддержка
  - Главный администратор
- Роль хранится в `admins/{uid}` и дублируется в `users/{uid}.adminRole`.
- Только два исходных главных администратора могут назначать/снимать роли.

### 2FA для администраторов
- Добавлен отдельный экран «Безопасность админа».
- Используется стандартный TOTP (6 цифр, период 30 секунд).
- Ключ можно подключить через QR-код или ввести вручную в приложение-аутентификатор.
- Секрет хранится в закрытой подколлекции `users/{uid}/security/adminTotp`.
- При входе администратор с включённой TOTP проходит дополнительный шаг после обычной 2FA.
