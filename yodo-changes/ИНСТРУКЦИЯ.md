## 4. Расширенное обучение (уже в новом OnboardingScreen.kt)

При запуске обучения пользователь выбирает формат:
- **Быстрое** — 5 обзорных карточек (как раньше).
- **Полное** — обзор чатов / групп / каналов + **интерактивная практика**:
  - самому отправить демо-сообщение (ввод + кнопка отправки);
  - сделать **долгий тап** по сообщению → открывается меню (ответить/копировать/…);
  - добавить участника в демо-группу;
  - подписаться на демо-канал.

Всё изолировано — демо-элементы не влияют на реальные чаты. Правки навигации не нужны.
Повторно открыть обучение можно, как и раньше, из Настроек
(`Routes.OnboardingReplay` → тот же `OnboardingScreen`).
