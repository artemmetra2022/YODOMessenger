# Оставшиеся предложения по оформлению YODO в стиле Telegram

Этот список содержит только задачи, которые после проверки текущего кода ещё не реализованы полностью или требуют дополнительной доработки.

## 1. Список чатов

Файл: `app/src/main/java/app/yodo/messenger/features/chats/ChatListScreen.kt`

- Привести строки списка к более компактной высоте около `72 dp`.
- Добавить отдельное заметное оформление закреплённых чатов.
- Показывать имя отправителя в превью последнего сообщения группового чата: `Алексей: текст`.
- Реализовать полноценные свайп-действия:
  - вправо — отметить прочитанным;
  - закрепить/открепить;
  - отключить звук;
  - архивировать;
  - удалить.
- Добавить полноценный поиск списка чатов с фильтрами и действиями над результатами.
- Сделать вкладки папок компактнее.

## 2. Шапка чата

Файл: `app/src/main/java/app/yodo/messenger/features/chats/ChatScreen.kt`

- Показывать в шапке группы строку `N участников`.
- Уточнить групповой статус набора текста до Telegram-вида, например `печатает: Алексей`.
- Добавить звонки и видеозвонки, если они входят в scope проекта.
- Добавить уменьшение или изменение прозрачности шапки при прокрутке.
- Добавить закреплённые сообщения в виде отдельной панели под шапкой, если текущая панель не покрывает этот сценарий полностью.

## 3. Пузырьки сообщений

Файл: `app/src/main/java/app/yodo/messenger/features/chats/ChatScreen.kt`

- Сделать ширину пузырей адаптивной — около `78%` ширины экрана вместо фиксированного ограничения `280 dp`.
- Показывать имя автора внутри каждого нужного группового пузыря.
- Назначать стабильный цвет имени каждому пользователю в группе.
- Доделать распознавание и кликабельность ссылок, usernames и упоминаний.
- Добавить двойное нажатие на сообщение для быстрой реакции.

## 4. Меню сообщения и режим выбора

Файлы: `ChatScreen.kt`, `ChatViewModel.kt`, `MessageRepository.kt`

- Добавить действие `Отметить как непрочитанное` в меню сообщения.
- Добавить действие `Информация о сообщении`.
- Реализовать мультивыбор сообщений.
- Добавить верхнюю панель режима выбора с количеством сообщений.
- Добавить пакетные операции:
  - переслать;
  - удалить;
  - закрепить;
  - поделиться.

## 5. Медиа и голосовые сообщения

Файлы: `ChatScreen.kt`, компоненты медиа и голосовых сообщений

- Добавить поддержку видео с кнопкой воспроизведения.
- Добавить настоящий прогресс загрузки медиа, а не только общий индикатор подготовки файла.
- Добавить единый жест закрытия для полноэкранного просмотра всех типов медиа.
- Улучшить waveform голосовых сообщений:
  - визуальный waveform;
  - точный прогресс воспроизведения;
  - выбор скорости `1x`, `1.5x`, `2x`.
- Добавить waveform и прогресс в preview записанного голосового сообщения.

## 6. Экран информации о группе

Файл: `app/src/main/java/app/yodo/messenger/features/chats/GroupInfoScreen.kt`

Базовые крупный аватар, название, описание и строка `N участников` уже реализованы. Остались следующие задачи:

- Добавить кнопку `Изменить` для редактирования группы.
- Добавить кнопку `Добавить участника`.
- Добавить кнопку `Поделиться ссылкой`.
- Добавить разделы:
  - общие медиа;
  - файлы;
  - ссылки;
  - голосовые сообщения.
- Добавить поиск по участникам.
- Добавить отдельный список администраторов с ролями `Владелец` и `Администратор`.
- Показывать закреплённые сообщения в информации о группе, если это требуется UX-потоком.
- Добавить ограничения участников.
- Добавить медленный режим.
- Добавить одобрение новых участников.
- Завершить полноценный invite-link flow.
- Добавить удаление группы отдельно от выхода из неё.

## 7. Фон чата

Файлы: настройки фона и `ChatScreen.kt`

- Добавить ненавязчивый Telegram-подобный паттерн как отдельный режим фона.
- Добавить раздельные настройки фона для светлой и тёмной схем.
- Добавить затемнение или повышение контраста поверх пользовательского изображения.
- Ограничить слишком яркие градиенты в Telegram-режиме.

## 8. Цветовая система

Файл: `app/src/main/java/app/yodo/messenger/ui/theme/ColorTheme.kt`

- Добавить отдельную тему `Telegram Classic`.
- Не использовать яркий цвет пользовательской темы для каждого пузыря в режиме `Telegram Classic`.
- Добавить отдельный цвет для непрочитанных сообщений.
- Провести проверку контраста текста и метаданных во всех светлых и тёмных темах.

Рекомендуемая палитра Telegram Classic:

```text
Светлый фон:       #FFFFFF
Фон чата:          #E7EBF0
Акцент:            #2AABEE
Исходящий пузырь:  #EEFFDE
Входящий пузырь:   #FFFFFF
Тёмный фон:        #0E1621
Исходящий тёмный:  #2B5278
Входящий тёмный:   #182533
```

## 9. Запись голосовых сообщений

- Добавить свайп влево для отмены записи.

## 10. Переходы и дополнительные жесты

- Добавить специализированный плавный переход между списком чатов и экраном чата.
- Добавить дополнительные Telegram-подобные переходы для открытия профиля, группы и media viewer.

## Приоритет внедрения

1. Мультивыбор сообщений и пакетные операции.
2. Адаптивная ширина пузырей, имена и цвета авторов в группах.
3. Видео, waveform и настоящий прогресс медиа.
4. Расширенный экран информации о группе.
5. Свайп-жесты списка чатов и записи голосовых сообщений.
6. Тема `Telegram Classic`, фон и проверка контраста.
7. Переходы между экранами.

## Брендинг

Сохранять название, логотип и графические ресурсы YODO. Использовать только общие UX-паттерны и визуальные принципы Telegram, не копируя его фирменные ресурсы.
