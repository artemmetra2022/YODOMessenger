# Страница-презентация YodoMessenger

## Где находится

Новая отдельная страница: `web/messenger/index.html`, URL после публикации — `/messenger/`.
Для текущего Firebase Hosting это `https://yodomessenger.web.app/messenger/`.
**Страница пока не опубликована.** Публикация выполняется вашим обычным процессом Firebase Hosting; конфигурацию и workflow менять не требуется. Веб-чат и вход остаются по прежнему адресу `/`.

## Что добавлено

- Самостоятельный адаптивный лендинг: чаты, группы, каналы, интерактивные доски, офлайн-режим поблизости, настройки безопасности, FAQ и открытый код.
- Светлая и тёмная темы по настройке системы, мобильное меню, клавиатурная навигация, видимый фокус, reduced-motion.
- Интерактивный демонстрационный макет чата и доски. Это не скриншоты приложения; имена и переписка вымышлены и подписаны как пример.
- Проверка последнего стабильного релиза через публичный GitHub API. Для готового APK — прямая ссылка, версия, дата и размер. Без готового APK — ссылка на страницу релиза. При ошибке, лимите API или выключенном JavaScript доступна ссылка на GitHub Releases.
- Кнопка повторной проверки. Автоматического скачивания, установки или циклического опроса нет.
- Ссылка «О мессенджере и скачивание APK» на существующем экране входа.
- Canonical, описание страницы, текстовые Open Graph-метаданные, JSON-LD и запись в sitemap.

Версия в блоке скачивания берётся из API, а не зашита в HTML. Скачивание идёт только с HTTPS-адресов раздела Releases указанного репозитория. Данные API выводятся как текст. Это проверка адреса, а не криптографическая проверка APK. Подтверждение установки остаётся за Android.

На лендинге нет сторонних шрифтов, аналитики или Firebase SDK. При открытии выполняется один запрос к GitHub API; повторный — только по кнопке. При таком запросе GitHub получает обычные сетевые данные посетителя.

## Файлы

Новые: `web/messenger/index.html`, `styles.css`, `page.mjs`, `releases.mjs`, `tests/web/messenger-releases.test.mjs` и этот документ.
Из существующих изменены только `web/index.html`, `web/styles.css`, `web/sitemap.xml`. Код Android, предыдущая «Мгновенная загрузка», настройки Firebase и админка сохранены без изменений.

## Локальный запуск

Из корня проекта:

```sh
python -m http.server 8080 --directory web
```

Открыть `http://localhost:8080/messenger/`. Используйте HTTP-сервер, а не двойной щелчок по HTML: браузерные модули JavaScript не рассчитаны на запуск через `file://`.

## Проверки

```sh
node --test tests/web/messenger-releases.test.mjs
```

12 тестов: правильный APK, фильтрация адресов, релизы без APK, черновики/prerelease, дата/размер, HTTP 403/404/429/500, сетевые ошибки, некорректный JSON и таймаут.

Дополнительно проверено в локальном Chromium: ширины 320, 390, 768, 1024 и 1440 px без горизонтального переполнения; меню и Escape, вкладки и клавиши стрелок/Home, раскрытие FAQ, ограничение повторных запросов, состояния «APK готов», «ожидание», лимит GitHub и пустой ответ. Выполнена визуальная проверка настольной/мобильной версии, тёмной темы, меню, доски, FAQ и состояний скачивания. Ответы GitHub для этих проверок моделировались; доступность реального будущего релиза не гарантируется.

Публикация сайта и сборка Android в рамках этой задачи не выполнялись.
