# Голосовые сообщения в веб-версии

## Что добавлено

- Запись голосовых сообщений в веб-клиенте (`web/index.html`, `web/app.js`):
  кнопка 🎤 рядом с полем ввода, панель записи с таймером, отмена (✕) и
  «остановить и отправить» (кнопка отправки или 🎤 ещё раз).
- Формат записи — AAC в M4A (`audio/mp4`), как в Android (`AudioUtils.kt`);
  в Firefox, где AAC-запись недоступна, — opus в WebM/Ogg. Битрейт 32 kbps моно.
- Ограничения, перенесённые из `AudioUtils.kt`: максимум 3 минуты записи
  (`MAX_RECORDING_MS`, автостоп) и итоговый base64 до 900 000 символов
  (`MAX_VOICE_BASE64_LENGTH`).
- Модель данных без изменений и полностью совместима с Android
  (`MessageRepositoryImpl.sendVoiceMessage`): поля `voiceBase64`,
  `voiceDurationMs`, `text = ""` в документе сообщения; превью в списке чатов —
  «🎤 Голосовое сообщение». Дополнительно веб-клиент пишет поле
  `voiceMimeType` — Android такие неизвестные поля при разборе игнорирует.
- Проигрывание: кнопка ▶/⏸ с длительностью рядом; mime определяется по полю
  `voiceMimeType`, а для сообщений без него (написанных в Android) — по
  сигнатуре контейнера (`ftyp`, EBML, `OggS`). Blob создаётся лениво, при первом
  прослушивании.
- Пересылка голосовых между чатами (аудио копируется вместе с сообщением),
  уведомления, reply-превью и lastMessage чата — с подсказкой «🎤 Голосовое
  сообщение».
- Запись автоматически останавливается и отменяется при смене чата, выходе из
  чата, выходе из аккаунта и закрытии страницы; микрофон-стрим всегда
  освобождается.
- Rate limiting — общий с текстовыми сообщениями (`sendRateLimiter`).

## Файлы

Изменённые: `web/index.html` (кнопка 🎤 и панель записи), `web/app.js`
(запись/отправка/проигрывание, превью, пересылка), `web/styles.css`
(панель записи и элемент голосового сообщения).

## Проверки

```sh
node --check web/app.js
```

Локальный запуск — как раньше:

```sh
python -m http.server 8080 --directory web
```

Открыть `http://localhost:8080/`, войти, открыть любой чат и нажать 🎤.
Запись требует HTTPS или localhost (кроме того — разрешение браузера на микрофон).
