# Продвинутое управление пользователями

Расширен раздел `Админка → Пользователи`.

## Поиск
- UID
- имя
- @username
- email

## Фильтры
- статус: новичок / активный / неактивный 30+ дней / заблокирован / на проверке
- класс
- страна
- дата регистрации от/до
- онлайн / оффлайн
- трудные пользователи: 3+ жалобы или 3+ блокировки

Онлайн определяется по `lastActiveAt` за последние 5 минут.

## Карточка пользователя
Показываются UID, контактные данные из доступного профиля, класс, регистрация, последняя активность, текущий статус, статистика жалоб/блокировок, активность за 30 дней и существующие административные данные.

Истории:
- действия администраторов;
- жалобы;
- блокировки;
- последние сообщения пользователя;
- обращения (`appeals` / `supportRequests` при наличии).

## Массовые операции
- заблокировать выбранных;
- разблокировать выбранных;
- изменить класс выбранным пользователям.

Изменение класса выполняется Firestore Batch и пишется в `adminAuditLog`.

## Данные
Поле класса пользователя: `users/{uid}.classId` (совместимо с `class_id` при чтении старых документов).

## Безопасность
Официальный администратор может изменять только `classId` других пользователей. Остальные поля пользователя по-прежнему изменяет владелец аккаунта.

## Индексы
Добавлены необходимые индексы для истории жалоб, сообщений, блокировок и `adminAuditLog`.
