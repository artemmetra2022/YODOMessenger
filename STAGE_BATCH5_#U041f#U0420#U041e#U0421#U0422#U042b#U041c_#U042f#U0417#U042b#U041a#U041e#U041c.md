# Что нового в этом обновлении (простыми словами)

Это обновление добавляет удобные мелочи и делает мессенджер приятнее в использовании.

## 1. Личный ID пользователя
- Теперь у каждого при регистрации появляется личный номер вида **YODO-XXXX-XXXX**.
- Он виден в профиле (у себя его можно нажать и скопировать).
- Этот ID **нельзя найти через поиск** — он нужен только для того, чтобы администратор мог заблокировать именно нужного человека.
- В чужом профиле администратор видит этот ID и кнопку блокировки с указанием причины.

## 2. Обновление списка чатов свайпом вниз
- Если потянуть список чатов вниз — он **обновится** (как в других мессенджерах), сверху появится кружок загрузки.
- Старый список «секретных чатов» по свайпу больше не открывается. Сама функция скрытия чатов осталась — она в меню по долгому нажатию на чат.

## 3. Создание группы стало удобнее
- Кнопка «Создать группу» теперь всегда видна внизу экрана (раньше могла прятаться за клавиатурой).
- Поле поиска участников стало круглее и аккуратнее.
- Выбранные участники показываются **компактными плашками в ряд** с маленькими аватарками (раньше были большими столбиком).

## 4. Аккуратные плашки таймера и отложенных сообщений
- Подписи «Исчезающие сообщения» и «Отложенные сообщения/посты» теперь в прямоугольнике со скруглёнными углами — смотрится опрятнее.

## 5. Кнопка «Комментарии» в каналах
- Если пост в канале очень короткий, кнопка комментариев больше **не растягивается на всю ширину** и не выпирает — теперь она по размеру текста.

---

> Все изменения не затрагивают ваши данные и настройки — это улучшения интерфейса и удобства.
