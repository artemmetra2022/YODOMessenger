# Отдельный экран сохранённых досок

Поверх версии 1.7.6 с выделением объектов и библиотекой досок.

- В настройках «Интерактивная доска» осталась одна строка «Сохранённые доски».
  Карточек досок в списке настроек больше нет, независимо от их количества.
- Строка открывает отдельный полноэкранный раздел с собственной прокруткой
  и кнопкой возврата к настройкам.
- Открытие рисунка ведёт в редактор. Назад из редактора возвращает в библиотеку;
  назад из библиотеки — в настройки. Позиция прокрутки библиотеки хранится отдельно.
- Список и его ViewModel загружаются только при открытии библиотеки, а не при
  посещении общих настроек доски. При возвращении из редактора список обновляется.
- Переименование, подтверждение удаления, обновление, изоляция аккаунтов и
  отображение старых/повреждённых файлов сохранены без изменения хранилища.
- Поиск настроек по сохранённым доскам по-прежнему ведёт к строке открытия.

Проверки этой правки: проверка синтаксиса Kotlin и связей маршрутов;
сверка полного архива с предыдущей выдачей. Добавлены два инструментальных
теста для отдельного списка из 80 досок, открытия/возврата и диалогов действий.
Они не запускались: в среде нет Android SDK/устройства. APK не собирался.
