# Этап 6 — общая доска в чате и настройки доски

Изменения исходников от 16.10.2026. Android-сборка, Gradle-тесты, деплой правил и проверка на
телефонах **не выполнялись** (в среде не было Kotlin/Gradle/Firebase). Код написан по образцу
существующих экранов и проверен только чтением и чисто-логическими тестами (`SharedBoardTest`,
не запускались).

## Что это

**Общая доска чата** — одна постоянная доска на личный чат или группу. Её видят и могут дополнять
все участники чата. В самом чате она показывается **живой карточкой** над списком сообщений:
все изменения участников появляются там сразу, но рисовать в карточке нельзя. Чтобы что-то
добавить, нужно **нажать на доску** — откроется редактор (карандаш, маркер, фигуры, текст, формулы,
ластик, умные фигуры, привязка к сетке, отмена/повтор).

- Создать доску: в чате меню вложений → «Общая доска чата» (только личные чаты и группы).
  До этого карточки в чате нет.
- Карточку можно свернуть нажатием на заголовок. В заголовке — число объектов и время последнего
  изменения. Каналы, поддержка и «Избранное» общей доски не имеют.
- Это отдельная функция: она не заменяет «Интерактивную доску» (локальные проекты, PNG в чат,
  сессии «рядом» и онлайн), которая работает как раньше.

## Как устроено

Один документ Firestore на каждый объект рисунка, как в протоколе совместной доски объекты только
добавляются и удаляются целиком, поэтому правки разных людей не конфликтуют:

| Путь | Назначение |
|---|---|
| `chats/{chatId}/sharedBoard/meta` | название, сетка, кто и когда менял в последний раз |
| `chats/{chatId}/sharedBoardObjects/{id}` | JSON одного объекта (тот же формат, что у файла доски), неизменяемый |

- Живые обновления — слушатели Firestore; свои изменения видны сразу, ещё до подтверждения сервером.
- Объекты проверяются строго при чтении (границы листа, размеры, формулы); испорченные или чужие
  пропускаются. Лист фиксирован 1200×900, фона-картинки у общей доски нет.
- Отмена/повтор — личные для каждого: отменяется только то, что сделали вы, а объекты, которые уже
  изменили другие, не трогаются.
- Предел — 300 объектов; при превышении показываются первые 300.
- Записи идут группами ≤ 10 (у правил Firestore есть лимит обращений `get()` на запрос).

## Настройки (Настройки → «Интерактивная доска»)

| Настройка | По умолчанию |
|---|---|
| Показывать доску в чате | вкл |
| Размер доски в чате (маленькая 140 / средняя 200 / большая 300 dp) | средняя |
| Сворачивать доску в чате по умолчанию | выкл |
| Цвет линии по умолчанию (7 цветов) | чёрный |
| Толщина линии по умолчанию (2/4/8/12 px) | 4 px |
| Умные фигуры | вкл |
| Привязка к сетке | выкл |
| Вибрация при выравнивании | вкл |
| Сетка новых досок (клетка / точки / без сетки) | клетка |
| «Сбросить настройки доски» | — |

Настройки применяются в обоих редакторах (локальном и общем) при открытии и для новых досок;
уже существующие доски они не меняют. Раздел есть в списке категорий и в поиске по настройкам.

## Безопасность и ограничения

- **Содержимое общей доски идёт через сервер без сквозного шифрования**: его видят участники чата и
  владелец проекта Firebase. В редакторе и в настройках есть предупреждение.
- Доступ — только участникам чата (правила Firestore проверяют `participantIds` и тип чата).
  Любой участник группы может рисовать, стирать чужие объекты и менять сетку; ролей и запрета
  редактирования для отдельных участников нет. Удалить доску целиком нельзя (удаляются объекты).
- Если участник вышел из чата, доступ к доске он теряет, но объекты, которые он нарисовал, остаются.
- Расходы Firebase: каждая правка — запись, и чтение у каждого участника с открытым чатом. Карточка
  держит живую подписку, пока открыт чат. Для больших групп оцените квоты.
- Карточка перерисовывается целиком при каждом изменении; на очень насыщенной доске это нагрузка
  на слабые телефоны.
- Не реализовано: ролевые права, история изменений, фон-картинка, несколько досок в чате,
  отдельные доски для тем форума, закрепление доски, уведомление об изменениях.

## Что нужно сделать перед включением

1. **Развернуть `firestore.rules`** (правила `sharedBoardAllowed`, `sharedBoard`, `sharedBoardObjects`).
   Правила используют `canvasUuid` из этапа 5, поэтому разворачивать нужно файл целиком.
2. Собрать приложение и прогнать JVM-тесты (`SharedBoardTest` и существующие).
3. Проверить на двух телефонах: создание доски, живое появление рисунка в карточке у второго,
   открытие по нажатию, стирание чужого объекта, отмена/повтор, сворачивание, группа из 3+ человек,
   выход из чата, поведение без сети (рисунки появятся после восстановления связи).
4. Проверить настройки: выключение карточки, три размера, сворачивание по умолчанию, цвет и толщина
   в обоих редакторах, сетка новой доски, вибрация, сброс, поиск по настройкам.
