Коротко о главном.

Как установить YodoMessenger?

Скачайте APK из последнего релиза и откройте файл на Android. Если система попросит, разрешите установку из этого источника. Затем подтвердите установку. Скачивайте приложение только из официального репозитория.

Какие устройства поддерживаются?

Приложение предназначено для Android 8.0 и новее. На компьютере можно использовать веб-версию. Отдельные приложения для iOS, Windows и macOS здесь не предлагаются; возможности веб-версии могут отличаться от Android.

Что делать, если релиз уже есть, а APK ещё нет?

APK может появиться после публикации самого релиза. Нажмите «Проверить ещё раз» или откройте релиз на GitHub. Страница не скачивает файлы автоматически — загрузка начинается только по вашей ссылке.

Как работает общение без интернета?

Устройства поблизости связываются через Bluetooth и Wi-Fi Direct. У обоих участников должен быть YodoMessenger с открытым офлайн-режимом и необходимыми разрешениями. Для удалённой переписки обычным способом нужен интернет.

Где посмотреть исходный код и изменения?

В репозитории проекта на GitHub. Описание каждого обновления находится в разделе Releases, а краткая история версий также доступна в приложении.
