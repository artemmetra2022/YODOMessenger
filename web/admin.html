Сводка по разделу «Школа»

Раздел «Школа»

Скрытие действует глобально для всех пользователей (кроме админов).

Пометка актуальности расписания

Показывается на экране «Расписание и звонки» в приложении.

Дата каникул

Дата начала каникул для отсчёта «До каникул» на экране «Расписание и звонки» в приложении. Пустое поле или «-» — используется зашитая дата из сборки.

Безопасность входа

Баннер для пользователей

Показывается вверху веб-версии мессенджера. Пустые даты — показывать всегда, пока включено.

Новости

Новая новость

После публикации push-уведомление подписчикам отправит воркер (в течение ~5 минут).

Опубликованные

Опросы

Новый опрос

После создания push-уведомление отправит воркер. Один голос на пользователя.

Все опросы

Официальный канал

Новый пост

Пост публикуется в официальный канал YodoMessenger и виден всем пользователям. Подписчикам push отправит воркер (в течение ~5 минут). Тема показывается отдельной плиткой — как в приложении.

Последние посты

Push-центр

Новая рассылка

Уведомление отправит push-воркер в течение ~5 минут. В уведомлении показываются заголовок и текст (текст обрезается до 200 символов).

История рассылок

Последние 50 рассылок. «В очереди» — воркер ещё не обработал.

Вопросы учеников

Неотвеченные вопросы со страниц всех учителей. Ответ виден ученику на странице учителя.

Учителя

Создать профиль учителя

Профили и привязки

Привязка даёт учителю доступ к «Моей странице учителя»: файл урока и ответы на вопросы.

Вопросы:

Ответ виден ученикам на странице учителя. Скрытие убирает вопрос с страницы.

Идеи

Предложения учеников из «Оценка и идеи». Удаление запрещено правилами безопасности — идеи только читаются.

Отзывы

Оценки раздела (1–5 звёзд). Только просмотр — удалять отзывы нельзя.

Жалобы

Все жалобы из всех чатов, включая обжалования блокировок. Удаление сообщения и блокировка автора закрывают жалобу; пользователь получает push.

Поддержка

Обращения в поддержку

Ограничить доступ к поддержке

Мягкая мера: пользователь остаётся в приложении, но не может писать в свой чат поддержки. Проверяется и на сервере (firestore.rules), и в приложении.

Действующие ограничения

Шаблоны ответов

Хранятся локально в этом браузере. «Вставить» подставляет текст в поле ответа открытой переписки.

Пользователи

Поиск аккаунта

По имени, @username или публичному ID (YODO-…-…). Карточка показывает профиль и статус блокировки.

Выгрузка всех аккаунтов (имя, контакты, регистрация, активность) в CSV для Excel.

Все пользователи

Профиль

Блокировки

Заблокировать по UID

UID можно скопировать в разделе «Пользователи» или в Firebase Console → Authentication. Заблокированный видит причину и может подать обжалование — оно появится в разделе «Жалобы».

Заблокированные аккаунты

Аудит

Журнал действий администраторов (adminAuditLog): блокировки, настройки и действия этой панели. Последние 50 записей.

Привязка аккаунта учителя

Найдите аккаунт учителя по имени, @username или ID из профиля (YODO-…-…). Учитель должен быть зарегистрирован в мессенджере.

Файл урока:

Ссылка на файл (Google Drive и т.п.) и описание. При смене ссылки подписчики получат push, а прежняя версия попадёт в историю на странице учителя.
