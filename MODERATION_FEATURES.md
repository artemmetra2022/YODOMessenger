# YODO Messenger — автоматическая модерация

Добавлены три функции:

1. **Автоматические правила фильтрации**
   - глобальные правила в Firestore `moderationRules`;
   - типы: «Содержит текст», «Регулярное выражение», «Домен ссылки»;
   - включение/выключение правила;
   - причины: Спам, Оскорбление, NSFW, Нарушение правил, Другое;
   - проверка выполняется в общем пути отправки сообщений, включая подписи к медиа.
   - для личных E2EE-чатов правило проверяется до шифрования.

2. **История удалённых сообщений**
   - архив в `moderationDeletedMessages`;
   - сохраняется исходный Firestore-документ сообщения;
   - срок восстановления — 30 дней;
   - после восстановления архивная запись удаляется;
   - просматривать и восстанавливать историю могут только главные администраторы.

3. **Причины удаления**
   - причина сохраняется вместе с записью истории;
   - удаление по жалобе получает причину самой жалобы;
   - автоматические удаления получают причину правила;
   - обычное административное удаление без указанной причины получает «Другое».

## Вход

В «Админка» добавлен раздел **Модерация** с двумя вкладками: **Автофильтр** и **Удалённые**.

## Firestore

Новые корневые коллекции:

- `moderationRules`
- `moderationDeletedMessages`

Правила Firestore добавлены в `firestore.rules`.
