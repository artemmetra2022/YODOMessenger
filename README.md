# YODO Messenger

**YODO** — мессенджер для Android с акцентом на приватность, офлайн-режим и удобный интерфейс. Написан на Kotlin с использованием Jetpack Compose и архитектурой MVVM.

## 📱 Возможности

### Мессенджинг
- Личные и групповые чаты, каналы
- Текст, фото, голосовые сообщения, ответы (реплаи), пересылка (одиночная и массовая)
- Реакции на сообщения, статусы прочтения
- Черновики сообщений, запланированная отправка
- Исчезающие сообщения (автоудаление по таймеру)
- Комментарии к постам в каналах
- Архивирование чатов (индивидуально для каждого участника)
- Папки чатов с ручным управлением составом
- Индикатор набора текста (typing), в том числе в группах
- Просмотр фото: pinch-to-zoom, double-tap zoom, swipe-to-dismiss, листание нескольких фото с датой

### Группы и каналы
- Режимы доступа: публичный открытый, публичный модерируемый (по заявке), скрытый (по ссылке/приглашению)
- Аватар и описание при создании, отображение режима доступа в карточке
- Управление ролями участников, приглашения в канал

### Модерация
- Жалобы на сообщения с указанием причины, очередь и инбокс жалоб для админов
- Панель администратора и журнал действий админов (admin log)
- Блокировка аккаунтов с указанием причины и экраном обжалования
- Удаление любых комментариев/сообщений главными админами

### Аккаунт и безопасность
- Авторизация: email/пароль с подтверждением почты, телефон (страница подключена, вход временно недоступен), Google Sign-In
- Подтверждение email при регистрации, восстановление пароля
- Двухфакторная аутентификация (2FA) — как для входа, так и для доступа внутри приложения
- Центр безопасности: управление активными устройствами/сессиями
- PIN-код блокировки приложения
- Мульти-аккаунт: переключение между аккаунтами без повторного входа, добавление нового аккаунта
- Индикатор надёжности пароля при регистрации
- Локальное шифрование (Tink) для чувствительных данных на устройстве

### Профиль и контакты
- Профиль: аватар, ник, username, био, локация, сайт; история изменений профиля
- Настройки приватности видимости профиля
- QR-код профиля и сканирование QR для добавления контакта
- Поиск пользователей, чатов и сообщений

### Офлайн и рядом
- Офлайн-обмен сообщениями через Bluetooth / Wi-Fi Direct без интернета (mesh-роутинг между устройствами)
- Обнаружение и чат с людьми поблизости (Nearby)

### Прочее
- Заметки (Notes) — раздел для личных заметок пользователя
- Инструменты (Tools) — вспомогательный экран утилит
- 8 цветовых тем оформления, тёмная/светлая тема
- Swipe-back жест для навигации назад
- Автозакрытие клавиатуры после отправки сообщения
- Push-уведомления через Firebase Cloud Messaging

### Пока не реализовано
- Экраны звонков (в навигации зарезервированы маршруты `Call` и `RecentCalls`, реализации UI ещё нет)
- Вход по номеру телефона (экран есть, функциональность отключена)
- Опросы в группах (модель данных заложена, UI и логика голосования не реализованы)

## 🏗 Архитектура

Проект следует архитектуре **MVVM**:

```
┌─────────────────────────────────────────────────────┐
│                    UI Layer                          │
│  (Jetpack Compose Screens & ViewModels)               │
├─────────────────────────────────────────────────────┤
│                 Domain Layer                          │
│  (Models, Interfaces, Business Logic)                 │
├─────────────────────────────────────────────────────┤
│                  Data Layer                            │
│  (Repositories, Firebase, Local Storage)               │
└─────────────────────────────────────────────────────┘
```

### Технологический стек

| Категория | Технологии |
|-----------|------------|
| **Язык** | Kotlin |
| **UI** | Jetpack Compose, Material 3 |
| **Архитектура** | MVVM |
| **DI** | Hilt |
| **Async** | Coroutines, Flow |
| **Backend** | Firebase (Firestore, Auth, Storage, Cloud Functions, FCM) |
| **Local DB** | Room, DataStore Preferences |
| **Navigation** | Navigation Compose |
| **Network** | Retrofit + OkHttp (Link Preview и др.) |
| **Serialization** | kotlinx.serialization |
| **Image Loading** | Coil |
| **Камера** | CameraX |
| **QR-коды** | ZXing |
| **Карты** | osmdroid |
| **Шифрование** | Google Tink |
| **Nearby / офлайн** | Play Services Nearby, Play Services Location, Bluetooth |
| **Google-аутентификация** | Credentials Manager, Google ID |
| **Build** | Gradle Kotlin DSL, KSP |

## 🚀 Быстрый старт

### Требования
- Android Studio (актуальная стабильная версия)
- JDK 17+
- Android SDK 34 (compile/target SDK)
- Минимальная версия Android: 8.0 (API level 26)
- Аккаунт Firebase с включёнными сервисами

### Настройка Firebase

1. Создайте проект в [Firebase Console](https://console.firebase.google.com/)
2. Добавьте Android-приложение с package name: `app.yodo.messenger`
3. Скачайте `google-services.json` и поместите в `app/`
4. Включите сервисы:
   - **Authentication** (Email/Password, Phone, Google)
   - **Cloud Firestore**
   - **Cloud Storage**
   - **Cloud Functions**
   - **Cloud Messaging**
5. Настройте **Firestore Rules** (см. `firestore.rules`)
6. Создайте индексы (см. `firestore.indexes.json`)
7. Разверните Cloud Functions из папки `functions/` (Node.js)

Подробный чек-лист — в `FIREBASE_SETUP_CHECKLIST.md`.

### Сборка проекта

```bash
git clone <repository-url>
cd yodo-messenger

# Debug-сборка
./gradlew assembleDebug

# Release-сборка
./gradlew assembleRelease

# Тесты
./gradlew test
```

APK будет создан в:
- Debug: `app/build/outputs/apk/debug/app-debug.apk`
- Release: `app/build/outputs/apk/release/app-release.apk`

## 🔒 Безопасность

- **Firestore Rules** — ограничивают доступ к данным уровнем авторизованных пользователей
- **Двухфакторная аутентификация** — отдельно для входа и для доступа к приложению
- **PIN-код** — локальная блокировка приложения
- **Управление устройствами** — просмотр и завершение активных сессий в центре безопасности
- **Локальное шифрование** — через Google Tink
- **Приватность профиля** — настройка видимости данных профиля
- **Модерация** — жалобы, блокировки аккаунтов, журнал действий администраторов
