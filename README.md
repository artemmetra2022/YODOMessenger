# YODO Messenger

**YODO** — мессенджер для Android с акцентом на приватность, офлайн-режим и удобный интерфейс. Написан на Kotlin с использованием Jetpack Compose и архитектурой MVVM.

## 📱 Возможности

### Мессенджинг
- Личные и групповые чаты, каналы
- Текст, фото, голосовые сообщения, ответы (реплаи), пересылка (одиночная и массовая)
- Реакции на сообщения, статусы прочтения
- Черновики сообщений, запланированная отправка
- Исчезающие сообщения (автоудаление по таймеру)
- Комментарии к постам в каналах
- Архивирование чатов (индивидуально для каждого участника)
- Папки чатов с ручным управлением составом
- Индикатор набора текста (typing), в том числе в группах
- Просмотр фото: pinch-to-zoom, double-tap zoom, swipe-to-dismiss, листание нескольких фото с датой

### Группы и каналы
- Режимы доступа: публичный открытый, публичный модерируемый (по заявке), скрытый (по ссылке/приглашению)
- Аватар и описание при создании, отображение режима доступа в карточке
- Управление ролями участников, приглашения в канал

### Модерация
- Жалобы на сообщения с указанием причины, очередь и инбокс жалоб для админов
- Панель администратора и журнал действий админов (admin log)
- Блокировка аккаунтов с указанием причины и экраном обжалования
- Удаление любых комментариев/сообщений главными админами

### Аккаунт и безопасность
- Авторизация: email/пароль с подтверждением почты, телефон (страница подключена, вход временно недоступен), Google Sign-In
- Подтверждение email при регистрации, восстановление пароля
- Двухфакторная аутентификация (2FA) — как для входа, так и для доступа внутри приложения
- Центр безопасности: управление активными устройствами/сессиями
- PIN-код блокировки приложения
- Мульти-аккаунт: переключение между аккаунтами без повторного входа, добавление нового аккаунта
- Индикатор надёжности пароля при регистрации
- Локальное шифрование (Tink) для чувствительных данных на устройстве

### Профиль и контакты
- Профиль: аватар, ник, username, био, локация, сайт; история изменений профиля
- Настройки приватности видимости профиля
- QR-код профиля и сканирование QR для добавления контакта
- Поиск пользователей, чатов и сообщений

### Офлайн и рядом
- Офлайн-обмен сообщениями через Bluetooth / Wi-Fi Direct без интернета (mesh-роутинг между устройствами)
- Обнаружение и чат с людьми поблизости (Nearby)

### Прочее
- Заметки (Notes) — раздел для личных заметок пользователя
- Инструменты (Tools) — вспомогательный экран утилит
- 8 цветовых тем оформления, тёмная/светлая тема
- Swipe-back жест для навигации назад
- Автозакрытие клавиатуры после отправки сообщения
- Push-уведомления через Firebase Cloud Messaging

### Уже реализовано
- Личные и групповые чаты, каналы, комментарии к постам и форумные темы групп.
- Текстовые сообщения, ответы, одиночная и массовая пересылка, реакции, редактирование, удаление и статусы прочтения.
- Фото, альбомы, документы и голосовые сообщения; preview медиа перед отправкой и индикатор подготовки.
- Просмотр фото с pinch-to-zoom, double-tap zoom, swipe-to-dismiss и листанием альбома.
- Сообщения «на один просмотр», исчезающие сообщения и запланированная отправка.
- Опросы: создание, анонимность, множественный выбор, викторины, автозакрытие, голосование и досрочное закрытие.
- Черновики, индикатор набора текста, быстрые реакции и скрытие клавиатуры при отправке или прокрутке.
- Архивирование чатов, папки чатов, закрепление сообщений и сохранение сообщений в избранное.
- Публичные, модерируемые и скрытые каналы; роли, приглашения и базовое управление каналами.
- Жалобы, очередь модерации, блокировка пользователей, апелляции и журнал действий администраторов.
- Регистрация и вход по email, Google Sign-In, восстановление пароля и подтверждение email.
- Реализован код входа по телефону и соответствующий репозиторий, но экран временно отключён в UI.
- 2FA, PIN-блокировка, ложный PIN для скрытых чатов, центр безопасности и управление устройствами.
- Профиль, username, приватность полей, QR-код и сканирование QR для добавления контакта.
- Офлайн-переписка через Nearby/Bluetooth/Wi-Fi Direct, mesh-маршрутизация и передача медиа.
- Профили пользователей в офлайн-чатах и обработка статусов офлайн-сообщений.
- Заметки, инструменты, поиск пользователей/чатов/сообщений, темы оформления и фон чата.
- Push-уведомления через Firebase Cloud Messaging и локальное шифрование чувствительных данных.

### Ещё не реализовано или требует отдельной доработки
- Голосовые и видеозвонки: сейчас есть только маршруты и экраны-заглушки `Call` и `RecentCalls`.
- Вход по номеру телефона в UI: backend и ViewModel существуют, но форма запроса номера отключена.
- Видео в сообщениях, кнопка воспроизведения и настоящий прогресс загрузки медиа.
- Улучшенный waveform голосовых сообщений, точный прогресс воспроизведения и скорости `1x`, `1.5x`, `2x`.
- Полноценные свайп-действия в списке чатов: прочитано, закрепить, отключить звук, архивировать и удалить.
- Полноценный поиск списка чатов с фильтрами и действиями над результатами.
- Мультивыбор сообщений с верхней панелью и пакетными операциями пересылки, удаления, закрепления и отправки.
- Действие «Отметить как непрочитанное» и расширенная информация о сообщении.
- Расширенное управление группой: редактирование, добавление участников, ссылка-приглашение, поиск по участникам и разделы общих медиа.
- Ограничения участников, медленный режим, одобрение новых участников и удаление группы.
- Полноценный invite-link flow для групп и каналов.
- Отдельные настройки фона для светлой/тёмной схем, паттерн и затемнение пользовательского изображения.
- Отдельная тема `Telegram Classic` и полная проверка контраста во всех темах.
- Свайпы для отмены или блокировки записи голосового сообщения.
- Специализированные плавные переходы между основными экранами.
- `SavedMessages` пока представлен экраном-заглушкой; отдельный полноценный экран избранного ещё не завершён.

## 🏗 Архитектура

Проект следует архитектуре **MVVM**:

```
┌─────────────────────────────────────────────────────┐
│                    UI Layer                          │
│  (Jetpack Compose Screens & ViewModels)               │
├─────────────────────────────────────────────────────┤
│                 Domain Layer                          │
│  (Models, Interfaces, Business Logic)                 │
├─────────────────────────────────────────────────────┤
│                  Data Layer                            │
│  (Repositories, Firebase, Local Storage)               │
└─────────────────────────────────────────────────────┘
```

### Технологический стек

| Категория | Технологии |
|-----------|------------|
| **Язык** | Kotlin |
| **UI** | Jetpack Compose, Material 3 |
| **Архитектура** | MVVM |
| **DI** | Hilt |
| **Async** | Coroutines, Flow |
| **Backend** | Firebase (Firestore, Auth, Storage, Cloud Functions, FCM) |
| **Local DB** | Room, DataStore Preferences |
| **Navigation** | Navigation Compose |
| **Network** | Retrofit + OkHttp (Link Preview и др.) |
| **Serialization** | kotlinx.serialization |
| **Image Loading** | Coil |
| **Камера** | CameraX |
| **QR-коды** | ZXing |
| **Карты** | osmdroid |
| **Шифрование** | Google Tink |
| **Nearby / офлайн** | Play Services Nearby, Play Services Location, Bluetooth |
| **Google-аутентификация** | Credentials Manager, Google ID |
| **Build** | Gradle Kotlin DSL, KSP |

│   ├── notes/                    # Заметки
│   ├── onboarding/                # Онбординг
│   ├── profile/                    # Профиль пользователя, QR, история профиля
│   ├── search/                      # Поиск
│   ├── security/                     # Центр безопасности, устройства, 2FA внутри приложения

├── offline/                # Офлайн-мессенджинг: mesh-роутер, Bluetooth/Wi-Fi Direct

## 🔒 Безопасность

- **Firestore Rules** — ограничивают доступ к данным уровнем авторизованных пользователей
- **Двухфакторная аутентификация** — отдельно для входа и для доступа к приложению
- **PIN-код** — локальная блокировка приложения
- **Управление устройствами** — просмотр и завершение активных сессий в центре безопасности
- **Локальное шифрование** — через Google Tink
- **Приватность профиля** — настройка видимости данных профиля
- **Модерация** — жалобы, блокировки аккаунтов, журнал действий администраторов
