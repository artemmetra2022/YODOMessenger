# YODO Messenger

**YODO** — мессенджер для Android с акцентом на приватность, офлайн-режим и совместную работу. Написан на Kotlin, Jetpack Compose и Firebase, архитектура — MVVM. Есть веб-версия (MVP), веб-админка раздела «Школа» и вход в веб по QR-коду.

> **Статус проверки.** Описанное ниже подтверждено по исходникам, но значительная часть последних изменений (виджеты, доски этапов 5–6, напоминания, пакет защиты личного текста, раздел «Школа») написана без Gradle и Android SDK: полная сборка, прогон тестов, деплой правил и проверка на устройствах ещё не выполнены. «Есть в коде» не означает «проверено и доступно пользователям». Актуальная версия приложения берётся из последнего GitHub-релиза (`artemmetra2022/YODOMessenger`).

## 📱 Возможности

### Чаты и сообщения
- Личные чаты, группы (в том числе форумные темы), каналы; Избранное — личный сохранённый чат.
- Текст, фото, альбомы, документы, голосовые сообщения; предпросмотр медиа перед отправкой.
- Ответы, одиночная и массовая пересылка, реакции, редактирование, удаление, мультивыбор сообщений, диалог «Информация о сообщении», закрепление.
- Статусы доставки и прочтения, индикатор набора текста (в том числе в группах).
- Упоминания `@username` в группах и каналах с отдельными каналами уведомлений.
- Черновики, запланированная отправка, исчезающие сообщения, сообщения «на один просмотр».
- Опросы и викторины: анонимность, множественный выбор, автозакрытие, досрочное закрытие.
- Устойчивая очередь исходящих **текстовых** сообщений (шифрование на устройстве, возобновление после перезапуска, лимит частоты отправки).
- Превью ссылок, Markdown в постах профиля и каналов.
- Список чатов: свайпы (закрепить, звук, архив, очистить, удалить, скрыть), архив, папки, скрытые чаты за PIN-кодом (в том числе ложный PIN).
- Просмотр фото: pinch-to-zoom, double-tap, swipe-to-dismiss, листание альбома.
- Скорости воспроизведения голосовых `0.5x / 1x / 1.5x / 2x`, ползунок позиции, отмена записи.
- Поиск пользователей, чатов и сообщений; поиск друзей по телефонной книге.

### Напоминания и чек-листы
- Напоминания о сообщениях на устройстве (WorkManager; Android может задерживать доставку).
- Совместные чек-листы в группах: общие отметки и имя отметившего участника.
- Подробности: [REMINDERS_AND_CHECKLISTS.md](REMINDERS_AND_CHECKLISTS.md).

### Доски (Canvas)
Рисование прямо из чата, поэтапно:
1. Локальная доска: рисунок, фигуры и распознавание фигур, сетка и шаблоны, импорт фото, PNG-превью.
2. Совместный Nearby-режим для двух устройств: сверка кода, курсоры, личная отмена.
3. Формулы — школьное подмножество LaTeX с предпросмотром и редактированием.
4. Онлайн-режим по одноразовому коду приглашения (10 минут, согласие ведущего).
5. Общая доска чата и настройки доски.
6. Библиотека «Мои доски» на отдельном экране с мультивыбором и массовым удалением.

PNG-превью и общая доска **не** являются E2EE. Документы: [CANVAS_FOUNDATION.md](CANVAS_FOUNDATION.md), [CANVAS_DRAWING.md](CANVAS_DRAWING.md), [CANVAS_COLLABORATION.md](CANVAS_COLLABORATION.md), [CANVAS_FORMULAS.md](CANVAS_FORMULAS.md), [CANVAS_ONLINE.md](CANVAS_ONLINE.md), [CANVAS_SHARED_BOARD.md](CANVAS_SHARED_BOARD.md), [BOARD_*_CHANGES.md](BOARD_AND_DOWNLOAD_CHANGES.md).

### Группы и каналы
- Режимы доступа: публичный открытый, публичный модерируемый (по заявке), скрытый (по приглашению).
- Роли участников, приглашения, ссылка-приглашение в канал (`yodo://channel/<id>`), комментарии к постам, статистика канала.
- Права на действия определяют, какие быстрые действия доступны в уведомлениях.

### Модерация
- Жалобы с причиной, очередь и инбокс жалоб, панель администратора, журнал действий.
- Блокировка аккаунтов с причиной и экраном обжалования, глобальные блокировки.
- Удаление любых комментариев и сообщений главными админами.

### Аккаунт и безопасность
- Вход: email/пароль с подтверждением почты, Google Sign-In, восстановление пароля. Вход по телефону реализован в коде, но экран отключён в UI.
- 2FA — для входа и для доступа внутри приложения; PIN-код блокировки; центр безопасности со списком устройств и завершением сессий.
- Мультиаккаунт: переключение без повторного входа, добавление аккаунта.
- **QR-вход в веб-версию:** одноразовая пара ключей ECDH в браузере, приватный ключ не покидает вкладку.
- **Защита личного текста:** запрет открытого fallback, шифрование подписей, цитат, правок и отложенного текста, SHA-256 отпечатки ключей, локальная фиксация ключа (TOFU) с предупреждением при смене. Это не E2EE для медиа и групп и не протокол с forward secrecy. Подробности и ограничения: [PRIVATE_TEXT_SECURITY.md](PRIVATE_TEXT_SECURITY.md).
- Локальное шифрование чувствительных данных (Tink, Android Keystore).

### Профиль и контакты
- Аватар с обрезкой, ник, username, био, локация, сайт; история изменений профиля; посты профиля.
- Новый дизайн профиля человека (статус «в сети», копирование полей по тапу).
- Приватность видимости полей с исключениями, чёрный список.
- QR-код профиля и сканирование QR для добавления контакта.

### Офлайн и рядом
- Переписка без интернета через Nearby (Bluetooth / Wi-Fi Direct) с mesh-маршрутизацией, передачей медиа и профилями пользователей.
- Люди рядом (Nearby) с картой на osmdroid.

### Школа
Раздел для гимназии: новости, учителя и страницы учителей, расписание звонков с живым статусом урока, отсчёт до каникул (дату может задать админ в `config/appSettings`), опросы, викторина, игра, отзывы, FAQ, раздел для родителей, режим учителя и админ-раздел. Веб-админка — `web/admin.html`.

### Виджеты рабочего стола (Jetpack Glance)
Четыре виджета с раскладками от 1×1 до 4×4: «Непрочитанные», «Погода», «Погода и непрочитанные», «Школа». Обновление раз в 15 минут, по push, при сворачивании приложения, входе/выходе и смене города. В виджеты попадают только названия чатов и числа, скрытые чаты — никогда; при PIN-коде или скрытых превью показываются только числа. Подробности: [WIDGETS.md](WIDGETS.md).

### Уведомления
- Push через Firebase Cloud Messaging, отдельные каналы для упоминаний.
- Быстрый ответ, «Прочитано» и локальное «Отключить звук» из уведомления (доступность зависит от типа чата и прав).
- Тихие часы по времени суток (с переходом через полночь), пауза, скрытие превью.

### Обновления приложения
- Проверка релизов GitHub, обычная и «Мгновенная загрузка» (`InstantUpdateService`) с процентами, подтверждение установки, история релизов.
- Release-сборка и публикация APK по push в `main`, подпись постоянным ключом из GitHub Secrets.

### Прочее
- Погода (met.no), город при регистрации с проверкой по геокодеру.
- Заметки, инструменты, обновлённое обучение (быстрое и полное).
- 8 цветовых тем, тёмная и светлая тема, русский и английский языки, swipe-back.

## 🚧 Не реализовано или требует доработки

- Голосовые и видеозвонки: маршруты `Call` и `RecentCalls` ведут на экраны-заглушки.
- Вход по телефону в UI: backend и ViewModel есть, форма отключена.
- Видео в сообщениях, видеосообщения, настоящий прогресс загрузки медиа.
- Очередь исходящих только для текста; для медиа и пересылки аналога нет.
- Пагинация истории: чат слушает всю историю без `limit`.
- Медленный режим, ограничения участников, одобрение новых участников; `config/moderationPolicy` описан в правилах, но клиентом не читается.
- Ссылки-приглашения для групп (для каналов есть).
- «Отметить как непрочитанное», раздел «Медиа, файлы, ссылки», фильтры поиска, стикеры и GIF, перевод сообщений.
- Проверка целостности и подписи APK до установки, стабильный/бета-каналы.
- Биометрия, passkeys, уведомление о входе с нового устройства, E2EE для групп и медиа.
- Личное расписание, домашние задания и классные чаты в «Школе».
- Маршрут `SavedMessages` — заглушка (Избранное работает через личный сохранённый чат).
- Часть строк интерфейса зашита на русском прямо в коде, без английских ресурсов.

Полный список и приоритеты: «Идеи для улучшения.txt».

## ⚙️ Конфигурация и сборка

- **Compile / Target SDK**: 34, **Min SDK**: 26, **Application ID**: `app.yodo.messenger`
- Версия берётся из флагов `-PversionName`, `-PversionCode`, `-PreleaseDate` (в CI — из последнего релиза). Без них — `0.1.0-mvp`.
- Release-подпись включается переменными окружения `YODO_KEYSTORE_PATH`, `YODO_KEYSTORE_PASSWORD`, `YODO_KEY_ALIAS`, `YODO_KEY_PASSWORD`.
- Нужен собственный `google-services.json` для проекта Firebase.

```bash
./gradlew :app:testDebugUnitTest      # JVM-тесты (38 файлов тестов, включая androidTest)
cd tests/firestore && npm test        # сценарии Firestore Rules (нужен эмулятор)
```

### CI/CD (GitHub Actions)
| Workflow | Назначение |
|---|---|
| `build-apk.yml` | сборка подписанного release-APK |
| `deploy-web.yml` | деплой `web/` в Firebase Hosting по push в `main` |
| `deploy-firestore-config.yml` | деплой правил и индексов Firestore |
| `send-push-notifications.yml` | отправка push по расписанию (каждые 5 минут) |

CI пока **не запускает** JVM- и Firestore-rules-тесты перед деплоем.

### Разрешения
Интернет и сеть, камера, микрофон, медиа и контакты, уведомления, Bluetooth, геолокация и Nearby Wi‑Fi Devices (офлайн и «Люди рядом»), установка пакетов (OTA), foreground service для загрузки обновлений, автозапуск (напоминания).

## 🔒 Безопасность

- **Firestore Rules** (`firestore.rules`) — основной барьер доступа; сценарии проверки в `tests/firestore`.
- **2FA, PIN, ложный PIN, управление устройствами, QR-вход** — см. выше.
- **Защита личного текста и ключей** — [PRIVATE_TEXT_SECURITY.md](PRIVATE_TEXT_SECURITY.md); перед деплоем правил нужен контролируемый порядок обновления клиентов и очистка старых превью (`tools/security-cleanup`, по умолчанию `DRY_RUN`).
- **Приватность профиля** и **модерация** (жалобы, блокировки, журнал).
- Лимиты отправки частично применяются только на клиенте и обходятся модифицированным APK.
