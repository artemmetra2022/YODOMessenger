# Обновления: загрузка, управление досками и интервал синхронизации

## Что изменено

- Экран и диалог обновления APK показывают процент и скачанные/общие мегабайты.
  Используются десятичные МБ (1 МБ = 1 000 000 байт). Если сервер не сообщает
  размер, показываются скачанные МБ и «размер неизвестен», без выдуманного процента.
- Локальная интерактивная доска: «Очистить всё» удаляет объекты, фон и шаблон,
  сбрасывает историю отмены и сохраняет результат. Название и сетка остаются.
  «Удалить доску» удаляет зашифрованный файл и резервные файлы с устройства.
  Удалять можно текущую доску или сохранённую доску из «Мои доски».
  Превью, ранее отправленные в чат, не удаляются.
  Во время Nearby/онлайн-сессии сначала нужно завершить совместную работу.
- Общая доска чата: очистка удаляет все объекты для всех участников, включая
  объекты за лимитом отображения (300). Удаление также скрывает карточку доски.
  Оба действия требуют подтверждения; любой участник чата, который мог рисовать,
  может очистить или удалить доску. История отмены сбрасывается у всех участников.
  В Firestore остаётся служебный документ-пометка без объектов: он предотвращает
  автоматическое восстановление удалённой доски открытыми редакторами.
  Новая доска создаётся явно кнопкой «Создать доску» в редакторе.
- Веб-админка: раздел обзора «Синхронизация досок», поле интервала в миллисекундах
  (0–5000). 0 — реальное время, 1000 — не чаще одного обновления в секунду.
  Значение хранится в config/appSettings.boardSyncIntervalMs и подхватывается
  приложениями без перезапуска.
  Для общей доски объединяются промежуточные чужие снимки, свои локальные записи
  показываются сразу. Первый снимок, очистка и удаление не ждут интервала.
  Для интерактивной онлайн-доски ограничивается частота отправки операций:
  команды не теряются, порядок сохраняется; подключение не замедляется.
  Настройка не относится к локальной доске без сессии и к Nearby.
  Это не периодический опрос: подписки Firestore сохраняются, экономия чтений
  Firestore не гарантируется.
- Сохранено предыдущее исправление границ отрисовки холста (панели инструментов).

## Обязательно перед использованием

1. Развернуть изменённые правила Firestore **до** распространения новой версии:
   `firebase deploy --only firestore:rules`
2. Развернуть веб-админку: `firebase deploy --only hosting`
3. Собрать и установить новый APK. Сборка: по существующему workflow проекта
   с Gradle 8.7, JDK 17, Android SDK и собственным google-services.json.
4. Открыть веб-админку администратором с доступом к глобальным настройкам и задать
   интервал. По умолчанию остаётся реальное время.

Изменения не опубликованы в GitHub и не развёрнуты в рабочем Firebase.
После первой очистки старые клиенты без поддержки поколения доски не смогут
добавлять объекты в неё: для совместной работы нужно обновить приложения участников.
Очистка общей доски требует соединения с сервером. Во время очистки запись закрыта.
При сетевом сбое повторить «Очистить всё» / «Удалить доску» — операция удалит остатки.
При одновременных очистках поколение и токен защищают от завершения старой операции
поверх новой; объекты нового поколения не удаляются старой очисткой.

## Проведённые проверки

- Локальный Firestore Emulator: весь набор `tests/firestore`, 124 теста успешно:
  34 checklist, 39 private-text-security, 20 canvas, 31 shared-board.
- Новые правила проверяют права участников/посторонних, поколение доски,
  блокировку записи при очистке, удаление 326 объектов с пагинацией,
  явное создание после удаления и границы административного интервала.
- Kotlin 2.2.20 + JUnit 4.13.2: 7 независимых JVM-тестов формата прогресса и интервала.
- Синтаксическая проверка Kotlin в разделах canvas/update; `node --check web/admin.js`;
  `git diff --check`.

Полная Android-сборка, Android instrumentation-тесты и проверка интерфейса на
устройстве **не выполнялись**: в рабочей среде нет Android SDK/Gradle/эмулятора.
Добавленный ранее CanvasDrawingViewClippingTest также пока не запускался.

Для повторения тестов правил: установить зависимости через `npm ci` в
`tests/firestore`, запустить локальный Firestore Emulator на 127.0.0.1:8088,
затем выполнить `npm test` в этой директории. Тесты используют demo-проекты,
не рабочую базу.

## Ручная проверка перед релизом

1. Загрузка APK: проценты + МБ, неизвестный размер, повтор после ошибки.
2. Локальная доска с фоном, рисунком, текстом, формулами: отмена подтверждения
   очистки ничего не меняет; подтверждение убирает содержимое и фон, после
   повторного открытия доска остаётся пустой. Удалённая доска не возвращается
   в «Мои доски», в том числе после перезапуска.
3. Два телефона в одном чате: очистка видна обоим, старая отмена не возвращает
   рисунки; удаление скрывает карточку у обоих и не создаёт её снова автоматически.
   Создание новой доски восстанавливает пустую карточку.
4. Сетевая ошибка во время удаления: повтор завершает очистку; нельзя рисовать
   в заблокированную доску. Проверить выход/повторный вход на экран.
5. Админка: 0, 250, 1000 и 5000 мс; изменение применяется на открытых экранах.
   Проверить общую доску и онлайн-сессию интерактивной доски; Nearby не меняется.
