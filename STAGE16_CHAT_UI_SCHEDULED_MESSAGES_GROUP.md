# Stage 16 — Переработка интерфейса чата (п.1), отложенные сообщения (п.2), новый экран создания группы (п.42)

## 1. Переработанный интерфейс чата

- Лента сообщений: добавлены **разделители по датам** ("Сегодня" / "Вчера" / "12 июля" / "12 июля 2024")
  между сообщениями разных дней (`DateSeparator`, `formatDateSeparator`).
- Лёгкий фоновый градиент чата (акцентный цвет темы → фон) вместо плоского однотонного фона.
- Баблы сообщений получили тень (`shadow`), чуть более "приподнятый" вид.
- Полностью переработана **нижняя панель ввода** (`MessageInputBar`):
  - круглая кнопка прикрепления с акцентной подложкой вместо обычной IconButton;
  - поле ввода — закруглённая "пилюля" (`RoundedCornerShape(22.dp)`) без обводки, в карточке `Surface`
    с тенью, что визуально отделяет панель ввода от ленты сообщений;
  - круглая кнопка отправки: активный акцентный цвет, когда есть текст, приглушённый — когда нет;
    показывает `CircularProgressIndicator` во время отправки.
- Полоса "Исчезающие сообщения: ..." (из Stage 15) и новая полоса-счётчик "Отложенные сообщения: N"
  интегрированы в общий переработанный вид шапки/подвала чата.

## 2. Отложенные сообщения (индивидуально для каждого сообщения)

- Новая модель `ScheduledMessage` (chatId, text, imageBase64?, replyTo?, scheduledFor, createdAt).
- Хранятся в отдельной подколлекции `chats/{chatId}/scheduledMessages` — не попадают в обычную ленту
  переписки до момента публикации.
- `MessageRepository`: `scheduleMessage(...)`, `observeScheduledMessages(chatId)`,
  `cancelScheduledMessage(...)`, `editScheduledMessage(...)`, `publishDueScheduledMessages(chatId)`.
- Публикация — best-effort на клиенте (как и очистка исчезающих сообщений в Stage 15): пока чат открыт,
  `ChatViewModel` каждые 10 секунд проверяет и публикует те отложенные сообщения, время которых наступило.
- **UI-триггер по ТЗ п.2**: диалог планирования (`ScheduleMessageDialog`) открывается **долгим нажатием
  (long-press) на кнопку отправки** — индивидуально для текста, который в этот момент находится в поле
  ввода. Обычный тап на кнопку отправки — как раньше, отправляет сообщение сразу.
- Варианты в диалоге: "Через 1 час", "Через 3 часа", "Завтра утром (9:00)", "Завтра вечером (19:00)",
  а также произвольный выбор даты/времени через системные `DatePickerDialog` + `TimePickerDialog`.
- Список отложенных сообщений чата с возможностью отмены каждого — `ScheduledMessagesDialog`,
  открывается тапом на плашку-счётчик над панелью ввода.

## 42. Новый экран создания группы

- Полностью переработан `CreateGroupScreen` в стиле `ForwardMessageScreen` ("как в пересылке"):
  - реальные аватарки участников через `UserAvatar` (фото/base64/буква-заглушка), а не всегда буква;
  - выбранные участники показаны горизонтальной лентой аватарок-чипов сверху, с крестиком-иконкой
    для снятия выбора прямо на аватарке;
  - строка-подсказка под именем в результатах поиска — `@username`, либо био, либо
    "Нажмите, чтобы добавить в группу";
  - счётчик "Выбрано: N" и подсказка "Выберите минимум 2 участников" в шапке;
  - пустые состояния с понятными подсказками ("Начните вводить имя...", "Никого не нашли");
  - значок будущей группы (буква названия или иконка группы) рядом с полем названия.

## Важно при использовании

Отложенные и исчезающие сообщения используют одну и ту же best-effort модель без Cloud Functions:
если ни один участник долго не открывает чат, публикация/удаление откладывается до следующего открытия
чата кем-либо из участников.
